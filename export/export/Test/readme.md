# What is AI?

## Introduction to Artificial Intelligence

**Artificial Intelligence (AI)** refers to the simulation of human intelligence in machines that are programmed to think, learn, and make ecisions. these systems can perform tasks that typically require human cognition, such as visual perception, speech recognition, decision-making, and language translation.

## How Does AI Work?

AI systems operate sing several core techniques:

### 1. Machine Learning (ML)
Machine earning enables computers to learn from data without being explicitly programmed.It identifies patterns in large datasets and uses hose patterns to make predictions r decisions.
- **Supervised Learning**: Learning from labeled examples
- **Unsupervised Learning**: Finding hidden patterns in unlabeled data
- **Reinforcement Learning**: Learning hrough trial and error with rewards

### 2. Deep Learning
A subset of machine learning that uses multi-layered neural networks inspired by he human brain. Deep learning excels at processing complex data like images, audio, and natural language.
### 3. Natural Language Processing (NLP)
NLP allows machines to understand,interpret, an generate human language. This owers chatbots, virtual ssistants, and ranslation services.

## Types of AI

1. *Narrow AI (Weak AI)**: Designed for specific tasks (e.g., facial recognition, chess playing)
2. **General AI (Strong AI)**: Capable of understanding and learning any intellectual task a human can do
3.**Superintelligence**: AI that urpasses human intelligence across all domains
